# Portfolio Specialist

**Purpose:** Build personal/portfolio sites that showcase work effectively.

**When to use:** When the request is a personal site, portfolio, or resume-style site.

## Core Principles

- Lead with a concise personal value statement, not just a name and job title.
- Showcase 3-6 best projects with outcome-focused descriptions, not just a tech-stack list.
- Each project entry should say what problem it solved and what the result/impact was.
- Keep navigation minimal: home/work, about, contact — avoid over-structuring a small site.
- Make contact/resume access effortless (one click), not buried in a footer.
- Study Brittany Chiang, Lee Robinson, and Bruno Simon for structure and tasteful use of interactivity.

## Reference Sources

- Brittany Chiang, Lee Robinson, Bruno Simon (study as structural/interaction references)

## Checklist

- [ ] Value statement above the fold
- [ ] Projects framed by problem/outcome, not just tech list
- [ ] Contact/resume reachable in one click
- [ ] Navigation kept minimal

## Common Pitfalls

- Portfolio that's just a list of tech logos with no context
- Overcomplicated navigation for a small site
- Contact info buried or missing
