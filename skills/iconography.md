# Iconography

**Purpose:** Use icons consistently and meaningfully.

**When to use:** Whenever icons are added to UI.

## Core Principles

- Stick to a single icon set/library (e.g. lucide-react) throughout the whole project for visual consistency.
- Icons should reinforce text labels, not replace them, unless the meaning is universally understood (search, close, menu).
- Keep consistent icon sizing (e.g. 16/20/24px) tied to the surrounding text size.
- Icon-only buttons need an accessible label (aria-label or tooltip), not just a visual icon.
- Avoid mixing filled and outline icon styles within the same context.

## Reference Sources

- lucide — https://lucide.dev/
- Heroicons — https://heroicons.com/

## Checklist

- [ ] Single icon library used consistently
- [ ] Icon-only buttons have accessible labels
- [ ] Consistent icon sizing tied to text scale

## Common Pitfalls

- Mixing icon libraries/styles in one UI
- Icon-only buttons with no accessible name
