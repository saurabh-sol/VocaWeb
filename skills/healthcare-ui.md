# Healthcare UI

**Purpose:** Design UI patterns for health/medical products with extra care for clarity and compliance context.

**When to use:** When building patient-facing or clinical interfaces.

## Core Principles

- Prioritize clarity and low cognitive load — healthcare users are often stressed; avoid dense, jargon-heavy screens.
- Use plain-language labels alongside any clinical terminology.
- Make emergency/urgent actions (e.g. 'contact provider now') visually distinct and always reachable.
- Handle sensitive data (PHI) with explicit access controls and avoid displaying it more broadly than necessary.
- Confirm destructive or high-stakes actions (canceling appointments, sharing records) with an explicit confirmation step.

## Reference Sources

- Nielsen Norman Group healthcare UX research

## Checklist

- [ ] Plain-language labels alongside clinical terms
- [ ] Emergency actions visually distinct and easy to find
- [ ] Sensitive data access explicitly controlled

## Common Pitfalls

- Dense jargon-only interfaces
- PHI displayed more broadly than necessary
- Destructive actions with no confirmation step
