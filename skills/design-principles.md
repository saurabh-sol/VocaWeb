# Design Principles

**Purpose:** General cross-cutting principles the agent should default to for any visual work.

**When to use:** As a background checklist for every design decision.

## Core Principles

- Contrast, repetition, alignment, proximity (CRAP principles) as a baseline sanity check for any layout.
- Whitespace is a design tool, not empty leftover space — use it to group/separate deliberately.
- Consistency beats novelty in functional UI; save novelty for hero/marketing moments.
- Every design decision should be justifiable by a user or business goal, not just aesthetic preference.
- When in doubt, simplify — remove elements until the page stops improving.

## Reference Sources

- Refactoring UI, Laws of UX (see website-designer.md)

## Checklist

- [ ] Layout checked against alignment/proximity/contrast/repetition
- [ ] Whitespace used intentionally
- [ ] Unnecessary elements removed

## Common Pitfalls

- Decoration with no functional or communicative purpose
- Inconsistent alignment across a page
