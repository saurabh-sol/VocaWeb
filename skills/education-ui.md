# Education UI

**Purpose:** Design UI patterns for learning platforms (courses, progress tracking).

**When to use:** When building course, lesson, or learning-progress interfaces.

## Core Principles

- Always show progress (percent complete, lessons done/total) prominently within a course.
- Break content into small, clearly titled units (lessons/modules) rather than long undifferentiated pages.
- Provide clear 'what's next' navigation at the end of every lesson/unit.
- Use immediate, specific feedback on quizzes/exercises rather than just right/wrong.
- Make it easy to resume exactly where the learner left off.

## Reference Sources

- Nielsen Norman Group e-learning UX research

## Checklist

- [ ] Progress indicator visible within courses
- [ ] Content chunked into clearly titled units
- [ ] Resume-where-left-off supported

## Common Pitfalls

- Long undifferentiated content pages with no chunking
- No visible progress indication
- Quiz feedback that's only right/wrong with no explanation
