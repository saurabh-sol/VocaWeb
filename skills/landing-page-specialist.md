# Landing Page Specialist

**Purpose:** Build high-converting marketing landing pages.

**When to use:** When the request is a marketing/product landing page rather than an app.

## Core Principles

- Structure: hero (value prop + CTA) -> social proof -> key features/benefits -> how it works -> testimonials -> pricing -> final CTA -> footer.
- Hero headline should state the outcome/benefit, not just the product name or feature list.
- Every section should have exactly one job — don't blend feature explanation with pricing on the same block.
- Use real (or clearly labeled placeholder) social proof — logos, numbers, testimonials — near the top third of the page.
- CTA copy should be specific ('Start free trial', 'Get your quote') rather than generic ('Submit', 'Click here').
- Study reference sites for pattern language, not literal copying: Stripe, Linear, Vercel, Framer, Raycast, Arc.

## Reference Sources

- Stripe, Linear, Vercel, Framer, Raycast, Arc Browser (study as references, don't copy content)

## Checklist

- [ ] Single clear value proposition in the hero
- [ ] Social proof placed early
- [ ] One job per section
- [ ] Specific, action-oriented CTA copy

## Common Pitfalls

- Vague hero copy that doesn't state a benefit
- Too many competing CTAs
- Copying reference sites' actual content/branding instead of just structural patterns
