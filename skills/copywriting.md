# Copywriting

**Purpose:** Write clear, persuasive, benefit-focused UI and marketing copy.

**When to use:** For headlines, CTAs, feature descriptions, and empty/error states.

## Core Principles

- Lead with the benefit to the user, not the feature name ('Never lose a file again' vs 'Automatic backups').
- Keep headlines under ~10 words; keep body copy scannable with short sentences and paragraphs.
- CTA buttons use specific action verbs ('Start free trial') instead of generic ones ('Submit', 'Click here').
- Write error messages that explain what happened and what to do next, not just 'Error occurred'.
- Match tone to audience: playful/casual for consumer products, precise/credible for B2B/enterprise.

## Reference Sources

- Copyhackers, Nielsen Norman Group UX writing guidance

## Checklist

- [ ] Headlines lead with benefit, not feature name
- [ ] CTA copy is specific and action-oriented
- [ ] Error messages explain cause + next step

## Common Pitfalls

- Generic 'Submit'/'Click here' CTAs everywhere
- Feature-first headlines with no clear user benefit
- Error messages with no actionable next step
