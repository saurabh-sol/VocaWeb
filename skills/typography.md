# Typography

**Purpose:** Choose and apply type systems that are readable and hierarchical.

**When to use:** Whenever setting up fonts/type scale for a new project or page.

## Core Principles

- Limit to 2 font families max: one for headings/display, one for body (or a single versatile family).
- Use a modular type scale (e.g. 1.25 ratio) rather than arbitrary font sizes.
- Body text: 16-18px base, 1.5-1.6 line-height for readability.
- Line length ~50-75 characters for body copy; constrain width with max-w utilities.
- Use font-weight and size for hierarchy before reaching for color or italics.

## Reference Sources

- Practical Typography — https://practicaltypography.com/

## Checklist

- [ ] Max 2 font families used
- [ ] Consistent modular type scale
- [ ] Body line-length constrained to readable width

## Common Pitfalls

- More than 2-3 font families in one design
- Body text under 16px
- Unconstrained line length on wide screens
